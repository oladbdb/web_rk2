Сайт магазина спортивной обуви реализован на PHP с использованием асинхронных запросов (AJAX), базы данных и серверной логики. Сайт доступен по адресу **http://www.baykovami.fwh.is/index.php**

Данные для входа администратора:

Логин: **admin@admin.admin**

Пароль: **admin**

Данные для входа пользователя:

Логин: **test@test.test**

Пароль: **test**

Сайт позволяет пользователям просматривать товары, добавлять их в корзину, оформлять заказы, оставлять отзывы, а администраторам — управлять пользователями, заказами и отзывами через специальную панель.

**Краткое описание папок и файлов**

Папка ajax содержит скрипты для обработки асинхронных запросов, таких как добавление товаров в корзину, оформление заказа, функционал администратора.

includes содержит файлы footer.php, header.php, которые содержат в себе элементы хедера и футера, которые подключаются к страницам сайта. db.php обеспечивает взаимодействие с базой данных, которая находится в папке database. В демонстрационных целях база данных представляет собой локальный SQLite файл sneakers.db. auth.php служит для регистрации и авторизации пользователя и предоставления доступа к страницам на основе роли пользователя. В папке admin находятся шаблоны таблиц для управления сайтом администратором.

Папка scripts содержит JavaScript-файлы, для скрытия и показа элементов и изменения вида их отображения, а также для отправки запроса на добавление товара в корзину.

Файлы admin_ представляют собой php-скрипты, позволяющие администратору управлять отзывами, заказами и пользователями. 

Файлы index.php, shop.php, product.php, cart.php, profile.php, purchase_history.php, feedback.php содержат в себе html-разметку основных страниц сайта и шаблонных элементов, а также php-скрипты для взаимодействия со страницами.

Файлы register.php, login.php, logout.php служат для обработки POST-запросов на регистрацию, авторизацию и выход из системы.
